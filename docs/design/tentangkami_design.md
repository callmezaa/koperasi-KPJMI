# DESIGN TASK

Design and implement a premium "About Us" section for the KPJMI (Koperasi Petani Jaya Makmur Indonesia) corporate website.

The objective is NOT to create another generic company profile section.

The result should feel handcrafted by a senior product designer from Apple, Stripe, Linear, or Vercel.

The interface must communicate professionalism, trust, collaboration, and sustainable agriculture while maintaining a clean, editorial, enterprise aesthetic.

# Layout Concept

Instead of a standard two-column layout, create an editorial composition.

Think of the section as a magazine spread rather than a website template.

Use asymmetric composition.

Large whitespace is mandatory.

Visual hierarchy should guide the eye naturally.
